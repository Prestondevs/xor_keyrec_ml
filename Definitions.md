# Technical Definitions for Project

* **Cryptanalysis**: Creating secret codes, or the study of cryptographic algorithms and breaking of those codes.  
[Reference: Geeks for Geeks](https://www.geeksforgeeks.org/computer-networks/cryptanalysis-and-types-of-attacks/)

* **Xor Cipher**: An encryption method using XOR as a key to encrypt and make ciphertext. This is useful as using the key again for an encrypted set of bites to decrypted it and get plaintext.  
[Reference 1: Geeks for Geeks - XOR Gates](https://www.geeksforgeeks.org/digital-logic/xor-gate/)  
[Reference 2: Geeks for Geeks - XOR Cyper](https://www.geeksforgeeks.org/dsa/xor-cipher/)

* **Frequency Analysis**: Is a subject in Cryptography that studies the frequency of letters in ciphertext. It counts the occurrence of each encrypted letter and from there finds the original unencrypted letter from that. XOR Cipher's are vulnerable to this method.    
[Refrence: 101 Computing Frequency Analysis](https://www.101computing.net/frequency-analysis/)
