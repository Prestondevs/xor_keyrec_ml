* **numpy**: Provides more options for arrays and faster operators on arrays. It's good for statistical and random simulations.  
[Documentation of numpy](https://numpy.org/doc/stable/)

* **matplotlib.pyplot**: A way to plot data. Can make histograms, pie charts, and other graphs.  
[Documentation of pyplot](https://matplotlib.org/stable/api/pyplot_summary.html)

* **Jypter Notebook**: A tool able that is a web application that is useful for showing results and resurch in general. Can output graphs, update markdown discriptions, and much more.  
[Jypter Website](https://jupyter.org/)
